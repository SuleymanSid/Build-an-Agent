# Build AI Agents with IBM Bob & watsonx Orchestrate

A polished GitHub Pages tutorial site that walks readers through using IBM Bob to build MCP tools and deploy an AI agent in watsonx Orchestrate — no manual work required.

**Live site:** `https://<your-username>.github.io/<repo-name>/`

## What's in here

| File/Folder | Purpose |
|---|---|
| `index.html` | The full tutorial page |
| `assets/style.css` | Stylesheet |
| `.github/workflows/deploy.yml` | Auto-deploy to GitHub Pages on every push to `main` |

## Enabling GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select **GitHub Actions**.
4. The first push to `main` triggers the workflow and your site goes live.
